# ClipForge Pro Editor v0.4

## Objetivo
Convertir ClipForge en un editor de Reels de escritorio con una experiencia densa, oscura y configurable, tomando como referencia de producto los flujos profesionales de editores de timeline.

## Incluido
- Timeline multicapa para Video, Audio, Imagen y Texto.
- Pistas bloqueables, mute, solo, renombrado, orden reubicable y alturas pequeña/normal/grande.
- Pistas colapsables y paneles Multimedia/Inspector colapsables.
- Arrastre desde Multimedia hacia la pista correspondiente.
- Snap y navegación por playhead.
- Marcadores de timeline con botón y atajo M.
- Menú contextual para pistas y clips.
- Transiciones de clip: Dissolve, Dip to black y Flash como metadatos de edición y feedback visual del Preview.
- Preview 9:16 y transporte con navegación rápida.
- Texto editable con posición libre.
- Audio con volumen por clip, fade in/out, mute/solo y sincronización del nivel durante el Preview.
- Mixer rápido para clips de audio.
- Perfil de edición Benjiwi basado en el proyecto de referencia aportado.
- Layout oscuro optimizado para ventana normal de Windows.
- Persistencia de tamaño/posición de ventana y paneles.
- Diagnóstico de GPU y Electron.

## Próximas capas de producto
La paridad completa con VEGAS Pro requeriría todavía un motor de composición/render unificado para todas las pistas, automatización de volumen/pan por keyframes, bus/master de audio, efectos OFX, máscaras Bézier, multicam, subtítulos temporizados, motor de transiciones GPU y render hardware por proveedor.
